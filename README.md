2020 COVID-19 Data Analysis Project
Overview
This project focuses on analyzing COVID-19 data from the year 2020. The dataset used in this analysis was downloaded from Our World in Data. The primary objective is to derive meaningful insights from the data collected during the pandemic. The dataset contains 49,016 rows of country-specific data, which is used to explore various aspects of the pandemic's impact.

The project is structured as a Jupyter Notebook and leverages Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data analysis and visualization. The analysis is divided into several sections, including data preparation, exploratory analysis, and answering specific questions related to the pandemic.

Project Structure
The project is organized into the following sections:

Data Preparation and Cleaning:

The dataset is loaded and cleaned to focus on relevant columns for analysis.

Rows corresponding to non-country data (e.g., "International" and "World") are removed.

Basic statistics and information about the dataset are displayed.

Exploratory Analysis and Visualization:

The dataset is grouped by country to analyze key metrics such as new cases, new deaths, total deaths, new tests, and total tests.

Visualizations are created to explore the distribution of COVID-19 cases and deaths across different countries.

The top 10 countries with the highest number of new cases, total deaths, new deaths, new tests, and total tests are identified.

Asking and Answering Questions:

The project addresses specific questions related to the pandemic, such as which countries have the highest occurrences of new cases and deaths.

Visualizations are used to support the findings and provide a clearer understanding of the data.

Key Insights
Top Countries with New Cases: The United States, India, and Brazil are among the countries with the highest number of new COVID-19 cases.

Top Countries with Total Deaths: The United States, Brazil, and the United Kingdom have the highest total number of deaths.

Top Countries with New Deaths: The United States, Brazil, and India lead in the number of new deaths.

Top Countries with New Tests: The United States, India, and Russia have conducted the most new tests.

Top Countries with Total Tests: The United States, India, and Russia have the highest total number of tests conducted.
